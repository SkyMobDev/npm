SkyMob npm packages

The packages for building module libraries for the SkyMob designer.

  • @skymobdev/sdk: develop, test and build a module library.
  • @skymobdev/standard-catalog-types: the standard catalog's modules, typed for the modules you build on them.
  • @skymobdev/cad-mock: the sample catalog the workbench and tests build modules against.

Use

Point the @skymobdev scope here in your project's .npmrc. No token or account is needed.

@skymobdev:registry=https://npm.skymob.app/

With pnpm, a project that holds new versions back (minimumReleaseAge) exempts these packages in pnpm-workspace.yaml, so a new SDK release installs right away:

minimumReleaseAgeExclude:
  - "@skymobdev/*"

Then install as from any registry:

pnpm add -D @skymobdev/sdk @skymobdev/standard-catalog-types @skymobdev/cad-mock
Published from SkyMobDev/npm, whose packages.list names every version served here.
